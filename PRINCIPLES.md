# Principles

Every skill in this plugin follows these.

## No documentation beats bad documentation

A wrong or stale document costs more than a missing one: it wastes the reader's time and makes them distrust every other document in the project.

- Write down only what the code or the user confirms. When unsure, leave it out.
- A view generated from the current code (a diagram, a summary) is disposable. Write it outside the repo and never commit it.
